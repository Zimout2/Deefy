# Deefy

Les fonctionnalités suivantes ont été réalisées :

1. Mes playlists : affiche la liste des playlists enregistrées en base de données ;

2. Chaque élément de la liste est cliquable et permet d’afficher une playlist qui devient la playlist courante stockée en session ;

3. Ajouter une piste : ajoute une nouvelle piste à la playlist courante ; un formulaire est affiché pour saisir les données de la piste. Cette fonctionnalité est accessible dans l’affichage d’une playlist.

4. Créer une playlist vide : un formulaire permettant de saisir le nom d’une nouvelle playlist est affiché. À la validation, la playlist est créée et stockée en BD ; elle devient la playlist courante.

5. Afficher la playlist courante : affiche la playlist stockée en session.

Lien du projet sur Webetu : https://webetu.iutnc.univ-lorraine.fr/www/e79153u/Deefy/iutnc/?action=default

Le code est issu du TD 13 avec des fonctionnalités supplémentaires pour correspondre au cahier des charges.

L'IA a été utilisée pour comprendre les différentes connexions avec les fonctionnalités mises en avant, issues des TP précédents. Cependant, toute la partie codage et la réflexion finale sur le projet ont été réalisées à la main.
